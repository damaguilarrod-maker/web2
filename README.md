Mundo Kuromi ♡
#Descripción del proyecto
Mundo Kuromi es una página web desarrollada como proyecto académico, inspirada en el personaje Kuromi de Sanrio. Presenta información del personaje, una galería de imágenes, contenido multimedia, un mapa de ubicación y un formulario de contacto.

#Tecnologías utilizadas
HTML5: estructura de la página web.
CSS3: diseño, colores, animaciones, sombras y efectos visuales.
Bootstrap 5: diseño adaptable y estilos del formulario.
Multimedia HTML: reproducción de video y audio.
Google Maps: visualización del mapa de ubicación.
#Características principales
Encabezado y menú de navegación.
Presentación del personaje Kuromi.
Galería de imágenes.
Sección multimedia con video MP4 y audio MP3.
Mapa de ubicación integrado.
Formulario de contacto con campos obligatorios.
Diseño adaptable a celulares y computadoras.
Animaciones, sombras y efectos al pasar el cursor.
Uso de las propiedades CSS float, clear y clearfix.

#Cómo ejecutar el proyecto
Descargar o clonar el repositorio.
Mantener los archivos multimedia y la carpeta img en las rutas indicadas.
Abrir el archivo index.html en un navegador web.
Disfrutar de la página Mundo Kuromi.
-Objetivo académico
Aplicar los conocimientos adquiridos sobre HTML5, CSS3 y Bootstrap para desarrollar una página web visualmente atractiva, organizada y adaptable a diferentes dispositivos.
